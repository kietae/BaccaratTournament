# Playing-card artwork

The 52 card faces in this directory come from the
[OpenDecks Public Domain and CC0 Playing Cards](https://github.com/AustinGabriel/OpenDecks-Public-Domain-and-CC0-Playing-Cards)
project.

- License: CC0 1.0 Universal / public domain
- Retrieved: 2026-08-27
- Local changes: files were renamed to compact rank/suit codes; face artwork is unchanged.

`Back.svg` is an original INSPIRE-themed vector card back created for this
workshop project. It does not reuse the OpenDecks back artwork.

The source repository's CC0 dedication is reproduced in `LICENSE` next to the
assets.
